# 💻 Ceyda Gokkaya — Portfolio Website

> ✨ Kişisel çalışmalarımı, projelerimi ve geliştirme sürecimi sergilediğim kişisel portföy web sitem.

---

## 🌐 Proje Hakkında

**CeydaGokkayaWebSite**, web geliştirme alanındaki çalışmalarımı ve projelerimi sergilemek amacıyla geliştirdiğim kişisel portföy web sitesidir.

Bu proje sayesinde hem kendimi ve yeteneklerimi tanıtmayı hem de geliştirdiğim projeleri tek bir platform üzerinden sergilemeyi amaçladım.

---

## 🚀 Özellikler

- 🎨 Koyu tema ve lila vurgulu, modern tasarım
- 📱 Telefon, tablet ve bilgisayarda uyumlu (responsive) yapı
- 🧭 Kolay ve anlaşılır navigasyon
- 💼 Proje kartları: teknoloji etiketleri, GitHub ve canlı site bağlantıları
- 🎓 Eğitim ve sertifikalar sayfası
- 📬 İletişim formu: mesajlar SQL Server veritabanına kaydedilir, basit spam koruması ve saatlik mesaj sınırı vardır
- 📊 Sayfa görüntülenme sayacı
- 🌐 Canlıda yayında: ceydagokkaya.com
