# CeydaGokkayaWebSite

Kendi portföy web sitem olan bu proje, Ceyda Gokkaya tarafından geliştirilmiştir.
Amaç, kişisel çalışmalarımı ve projelerimi sergileyebileceğim bir platform sağlamaktır.

## Teknolojiler
- HTML
- CSS
- ASP.NET Core

## Özellikler 
- Modern ve sade tasarım
- Mobil uyumlu (responsive)
- Kolay erişim ve gezinme

#3 Kurulum
1. Depoyu bilgisayarınıza klonlayın veya indirin.
2. Visual Studio'da proje dosyasını a.ın.
3.'F5' tuşuna basarak projeyi çalıştırın.
